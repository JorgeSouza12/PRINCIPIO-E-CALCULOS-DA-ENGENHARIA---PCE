# PBL 02

## Contexto

Temos uma corrente industrial que recebe continuamente uma mistura líquida formada por água (H₂O), etanol (C₂H₅OH) e metanol (CH₃OH). A partir das informações fornecidas, precisamos transformar os dados que estão em massa para uma base molar, para assim conseguirmos entender melhor a composição desta corrente.

---

## Vazão mássica total

Primeiramente, temos que encontrar a vazão mássica total da corrente. Para isto, basta somarmos as vazões dos três componentes que foram fornecidos no problema.

Temos 400 kg/h de água, 200 kg/h de etanol e 100 kg/h de metanol.

Então:

**m = 400 + 200 + 100**

**m = 700 kg/h**

Com isto, podemos afirmar que a vazão mássica total da corrente é de **700 kg/h**.

---

## Massa molar dos componentes

Para conseguirmos transformar a massa em quantidade de matéria, precisamos utilizar as massas molares fornecidas no problema.

Para a água (H₂O), temos uma massa molar de **18 g/mol**.

Para o etanol (C₂H₅OH), temos uma massa molar de **46 g/mol**.

Para o metanol (CH₃OH), temos uma massa molar de **32 g/mol**.

Com estas informações, podemos agora transformar as vazões que estão em kg/h para g/h e posteriormente encontrar a quantidade de matéria de cada componente.

---

## Conversão das vazões

Seguindo a lógica do problema, precisamos primeiro transformar as medidas para que elas fiquem compatíveis com as massas molares, que estão em g/mol.

Para a água:

**400 kg/h = 400.000 g/h**

Para o etanol:

**200 kg/h = 200.000 g/h**

Para o metanol:

**100 kg/h = 100.000 g/h**

---

## Quantidade de matéria da água

Agora podemos utilizar a relação:

**n = m/M**

Substituindo os dados da água:

**n = 400.000 g/h / 18 g/mol**

**n = 22.222,22 mol/h**

Com isto, temos que a vazão molar da água é de aproximadamente **22.222,22 mol/h**.

---

## Quantidade de matéria do etanol

Utilizando a mesma lógica:

**n = m/M**

Substituindo os valores:

**n = 200.000 g/h / 46 g/mol**

**n = 4.347,83 mol/h**

Com isto, temos que a vazão molar do etanol é de aproximadamente **4.347,83 mol/h**.

---

## Quantidade de matéria do metanol

Para o metanol também utilizamos a mesma relação:

**n = m/M**

Substituindo:

**n = 100.000 g/h / 32 g/mol**

**n = 3.125 mol/h**

Assim, a vazão molar do metanol é de **3.125 mol/h**.

---

## Quantidade de matéria total

Agora que conseguimos encontrar a quantidade de matéria de cada componente, podemos somar os três valores para descobrir a vazão molar total da corrente.

**n total = 22.222,22 + 4.347,83 + 3.125**

**n total = 29.695,05 mol/h**

Com isto, podemos afirmar que a vazão molar total da corrente é de aproximadamente **29.695,05 mol/h**.

---

## Fração molar

Depois de encontrar a quantidade de matéria total, podemos descobrir a fração molar de cada componente. Para isto, utilizaremos a relação:

**xᵢ = nᵢ / n total**

### Água

**x H₂O = 22.222,22 / 29.695,05**

**x H₂O = 0,74835**

### Etanol

**x C₂H₅OH = 4.347,83 / 29.695,05**

**x C₂H₅OH = 0,14641**

### Metanol

**x CH₃OH = 3.125 / 29.695,05**

**x CH₃OH = 0,10524**

Podemos fazer uma verificação somando as três frações molares:

**0,74835 + 0,14641 + 0,10524 = 1,000**

Com isto, podemos confirmar que os cálculos estão corretos, pois a soma das frações molares deve ser igual a 1.

---

## Percentual molar

Agora que temos as frações molares, podemos transformar estes valores em percentual molar. Para isto, basta multiplicar cada fração molar por 100.

### Água

**0,74835 × 100 = 74,835%**

### Etanol

**0,14641 × 100 = 14,641%**

### Metanol

**0,10524 × 100 = 10,524%**

Somando os valores:

**74,835 + 14,641 + 10,524 = 100%**

Com isto, também conseguimos confirmar que os valores encontrados estão corretos.

---

## Resultados finais

**H₂O**

- Vazão mássica: **400 kg/h**
- Vazão molar: **22.222,22 mol/h**
- Fração molar: **0,74835**
- Percentual molar: **74,835%**

**C₂H₅OH**

- Vazão mássica: **200 kg/h**
- Vazão molar: **4.347,83 mol/h**
- Fração molar: **0,14641**
- Percentual molar: **14,641%**

**CH₃OH**

- Vazão mássica: **100 kg/h**
- Vazão molar: **3.125 mol/h**
- Fração molar: **0,10524**
- Percentual molar: **10,524%**

**Totais**

- Vazão mássica total: **700 kg/h**
- Vazão molar total: **29.695,05 mol/h**
- Soma das frações molares: **1,000**
- Soma dos percentuais molares: **100%**

# Interpretação e lógica utilizada

### Questão 1 — Por que a fração molar não é igual à fração mássica?

A fração molar e a fração mássica acabam sendo diferentes porque estamos trabalhando com duas formas diferentes de enxergar a composição da corrente.

A fração mássica considera quanto temos de cada componente em relação à massa total, enquanto a fração molar considera quanto temos de cada componente em relação à quantidade total de mols.

Como cada substância possui uma massa molar diferente, uma determinada massa não representa a mesma quantidade de mols para todos os componentes. Por exemplo, a água possui massa molar de 18 g/mol, enquanto o etanol possui 46 g/mol.

Com isto, mesmo que tenhamos uma determinada quantidade em kg de cada substância, quando transformamos estes valores para mols, as proporções acabam mudando.

---

### Questão 2 — Qual componente apresenta a maior fração molar?

O componente que apresenta a maior fração molar é a **água (H₂O)**, com uma fração molar de **0,74835**, ou aproximadamente **74,835%**.

Isto acontece principalmente porque a água possui a maior vazão mássica da corrente, sendo 400 kg/h. Além disso, ela possui a menor massa molar entre os três componentes, com apenas 18 g/mol.

Com isto, quando transformamos os 400 kg/h de água para mols, chegamos a aproximadamente 22.222,22 mol/h, que é uma quantidade muito maior que a quantidade de mols dos outros dois componentes.

---

### Questão 3 — Por que a composição molar pode ser mais adequada para analisar uma reação química?

A composição molar pode ser mais adequada porque uma reação química acontece entre as moléculas das substâncias e as proporções das reações são normalmente apresentadas em mols.

Por exemplo, quando temos uma reação química, podemos saber quantos mols de um reagente são necessários para reagir com determinada quantidade de outro reagente. Desta forma, trabalhar com a composição molar facilita a análise das proporções entre os componentes.

Com isto, conseguimos ter uma visão mais adequada de quanto de cada substância realmente está disponível para participar de uma reação química, podendo posteriormente analisar questões como reagente limitante, quantidade de produto formado e quantidade necessária de reagentes.

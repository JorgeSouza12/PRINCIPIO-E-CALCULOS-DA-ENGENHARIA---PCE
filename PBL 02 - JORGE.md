# PBL 02 - JORGE

---

## Contexto

Temos uma corrente industrial que recebe continuamente uma mistura líquida formada por água (H₂O), etanol (C₂H₅OH) e metanol (CH₃OH). A partir das informações fornecidas, precisamos transformar os dados que estão em massa para uma base molar, para assim conseguirmos entender melhor a composição desta corrente.

---

## Vazão mássica total

Basta somarmos as vazões dos três componentes que foram fornecidos no problema.

Temos 400 kg/h de água, 200 kg/h de etanol e 100 kg/h de metanol.

Então:

m = 400 + 200 + 100

m = 700 kg/h

Com isto, podemos afirmar que a vazão mássica total da corrente é de 700 kg/h.

---

## Massa molar dos componentes

Para conseguirmos transformar a massa em quantidade de matéria, precisamos utilizar as massas molares fornecidas no problema.

Para a água, temos uma massa molar de 18 g/mol.

Para o etanol, temos uma massa molar de 46 g/mol.

Para o metanol, temos uma massa molar de 32 g/mol

Com estas informações, podemos agora transformar as vazões que estão em kg/h para g/h e depois encontrar a quantidade de matéria de cada componente.

---

## Conversão das vazões

Seguindo a lógica do problema, precisamos primeiro transformar as medidas

Para a água:

400 kg/h = 400.000 g/h

Para o etanol:

200 kg/h = 200.000 g/h

Para o metanol:

100 kg/h = 100.000 g/h

---

## Quantidade de matéria da água

Agora podemos utilizar a relação:

n = m/M

Substituindo os dados da água:

n = 400.000 g/h / 18 g/mol

n = 22.222,22 mol/h

Com isto, temos que a vazão molar da água é de aproximadamente 22.222,22 mol/h.

---

## Quantidade de matéria do etanol

Utilizando a mesma lógica da parte acima:

n = m/M

Substituindo os dados:

n = 200.000 g/h / 46 g/mol

n = 4.347,83 mol/h

Com isto, temos que a vazão molar do etanol é de aproximadamente 4.347,83 mol/h.

---

## Quantidade de matéria do metanol

n = m/

Substituindo:

n = 100.000 g/h / 32 g/mol

n = 3.125 mol/h

Assim, a vazão molar do metanol é de 3.125 mol/h.

---

## Quantidade de matéria total

Agora podemos somar os três valores para descobrir a vazão molar total da corrente.

n total = 22.222,22 + 4.347,83 + 3.125

n total = 29.695,05 mol/h

Podemos afirmar que a vazão molar total da corrente é de aproximadamente 29.695,05 mol/h.

---

## Fração molar

Utilizaremos a equação abaixo para encontramos a fração molar de cada componente da corrente:

xᵢ = nᵢ / n total

### Água

x H₂O = 22.222,22 / 29.695,05

x H₂O = 0,74835

### Etanol

x C₂H₅OH = 4.347,83 / 29.695,05

x C₂H₅OH = 0,14641

### Metanol

x CH₃OH = 3.125 / 29.695,05

x CH₃OH = 0,10524

---

## Percentual molar

Agora que temos as frações molares, podemos transformar estes valores em percentual molar. Para isto, basta multiplicar cada fração molar por 100, para assim acharmos a porcentagem.

### Água

0,74835 × 100 = 74,835%

### Etanol

0,14641 × 100 = 14,641%

### Metanol

0,10524 × 100 = 10,524%

---

## Resultados finais

H₂O

- Vazão mássica: **400 kg/h**
- Vazão molar: **22.222,22 mol/h**
- Fração molar: **0,74835**
- Percentual molar: **74,835%**

C₂H₅OH

- Vazão mássica: **200 kg/h**
- Vazão molar: **4.347,83 mol/h**
- Fração molar: **0,14641**
- Percentual molar: **14,641%**

CH₃OH

- Vazão mássica: **100 kg/h**
- Vazão molar: **3.125 mol/h**
- Fração molar: **0,10524**
- Percentual molar: **10,524%**

Totais

- Vazão mássica total: **700 kg/h**
- Vazão molar total: **29.695,05 mol/h**
- Soma das frações molares: **1,000**
- Soma dos percentuais molares: **100%**


# Interpretação e lógica utilizada

Questão 1 — Por que a fração molar dos componentes não é igual à fração mássica?
A fração mássica considera a massa de cada componente, enquanto a fração molar considera a quantidade de mols. Como cada substância possui uma massa molar diferente, os valores acabam sendo diferentes.

---

Questão 2 — Qual componente apresenta a maior fração molar?
A água (H₂O) apresenta a maior fração molar, com 0,74835 ou 74,835%. Isso acontece porque ela possui a maior vazão mássica e também a menor massa molar entre os componentes.

---

Questão 3 — Por que a composição molar pode ser mais adequada para analisar uma reação química?
Porque as reações químicas acontecem em proporções de moléculas e mols. Com a composição molar, conseguimos entender melhor quanto de cada componente está disponível para participar da reação e as proporções necessárias entre os reagentes.
